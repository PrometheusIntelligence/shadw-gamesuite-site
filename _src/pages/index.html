  • A fourth game and a fourth engine. The Holy Temple runs under the new templeos engine: gamec boots TempleOS in QEMU, the operating system compiles the game, and Forge keeps the serial log and screenshots.
  • The Game Store, v0.1. Sales as deeds signed with KeyForge keys, payment checks for every rail, and all four games listed.
  • Release builds outside the suite. The Holy Temple also builds a zip, a VirtualBox VM, Steam depots and itch.io channels with one command; signing them with KeyForge is the next step for G2.

Your engine stays your engine

The suite is not an engine. It holds only the thread between products: the project file, the CLI and, later, an engine plugin. Godot 4 was first (open source, so headless servers run with no licence questions); a JavaScript game needs no engine at all, and a HolyC game brings a whole operating system.

Honest about what is next

The build verb (G1), signed builds and real keys (G2), shipping to the mesh (G3), attacking your own game on staging (G4) and opening to outside studios (G5) are not built yet. Each product page says what is missing.
