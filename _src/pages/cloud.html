"deploy" · shadw.cloud

Ship it to the mesh

One command is meant to put the web build, the lobby and the game servers live, and to scale the servers to zero between matches.

G3 planned

What it will do for a game

  • A game app type in shadw.cloud's fluid.json: a static web build, a pool of server cells with a ws or udp service, and the licensing and lobby functions.
  • Lobby and matchmaking as ordinary functions with a small state store.
  • A preview address for every build, for playtests.
  • Crash dumps and telemetry into a per-game log.
  • First netcode: ws, turn-based; UDP into cells proven separately (decision G4).
