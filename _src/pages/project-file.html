shadw.game.json and the shadw game CLI · SHADW Game Suite The SHADW Game Suite's project file and CLI: one shadw.game.json names which product contract each part of a game fills; the shadw game CLI runs them. Godot 4 first. project-file

The thread

One project file, one CLI

shadw.game.json sits at the root of the game. Each section names an existing product contract; the suite adds no schema below it, and unknown fields are errors, so a typo never passes silently.

The CLI

VerbDoesState
initwrites the project file (and a Godot project)built
validatechecks the file, world params against Terrain, seats against spawnsbuilt
worldgenerates and locks the map; Godot scenebuilt
testruns the headless test under Forge; test.exclude leaves build output out of the copybuilt
timelinemerges every run's events, checks chainsbuilt
buildengine export under ForgeG1
sign, keyssigned builds, entitlementsG2
shipdeploy to shadw.cloudG3
attackdrills against stagingG4

Verbs not built yet exit with code 2 and name their phase.

Engines

engine.name is godot, unity, none (a JavaScript game such as Shadow Duel) or templeos. With templeos, a test command that starts with gamec runs the TempleOS backend: it boots TempleOS V5.03 in QEMU, the operating system compiles the HolyC game from source and runs its tests, and the serial log and screenshots become Forge artifacts. The Holy Temple's project file:

{
  "game": "the-holy-temple",
  "engine": { "name": "templeos", "version": "5.03", "export": "desktop" },
  "test": { "command": ["gamec", "run", ".", "--seconds", "900"], "timeout": "20m", "memory": "2Gi",
            "exclude": [".claude", "dist"] }
}

Godot 4 first

Decision G1 picked Godot 4: open source, so headless servers run with no licence questions, and GDExtension can load KeyForge's C ABI. The game folder is the Godot project. GDScript and C# (Godot .NET) both work: Brine & Brie: Shipwright is written in C#.

Try it

# Node 23.6 or later; shadw-terrain and shadw-forge checked out beside the suite
node src/cli.ts game init mygame --dir mygame
node src/cli.ts game world --dir mygame
node src/cli.ts game test --dir mygame

Not public yet. The suite's repositories are private while G1 finishes, so these commands are for the team today.
