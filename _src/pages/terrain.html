"world" · SHADW Terrain

Make the world from a seed

Name a map type and a seed in shadw.game.json. Terrain generates the map, the suite locks it, and Godot gets a scene it can load.

built (G0)

What it does for a game

  • shadw game world writes world/<game>.map.json, an SVG preview and world.lock.json with the map's content hash.
  • shadw game world --check regenerates the map and fails if the hash moved, so a Terrain change that alters your world is caught before it ships.
  • gameplay.spawnCount asks for up to 8 spawns; validate refuses a server with more seats than spawns.
  • For Godot it writes a scene with one ShadwMap node: a tile layer with collision on water and walls, and a marker per spawn and structure.
  • Terrain's 3D voxel worlds import into Godot too (a ShadwVoxelWorld node); not yet wired into shadw game world.

The section of the file it fills

"world": {
  "generator": "tactical-maps",
  "params": {
    "mapType": "coastal_outpost", "seed": 7, "width": 96, "height": 96,
    "gameplay": { "spawnCount": 8, "minimumSpawnDistance": 16 }
  }
}

The parameters are Terrain's own; the suite checks them with Terrain's validator and adds no schema of its own below them.
